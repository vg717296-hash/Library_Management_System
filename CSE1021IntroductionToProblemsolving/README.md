# Library Management System

## Project Description

The Library Management System is a simple Python-based project designed to manage books in a library.

The program allows the user to add books, view available books, search for books using their serial number, issue books, and return issued books.

A fine is also calculated when a book is kept for more than 7 days. The fine is ₹10 for each extra day.

## Features

- Add a new book
- Give each book a unique serial number
- View all books
- Search for a book using its serial number
- Issue a book
- Return only issued books
- Prevent issuing an already issued book
- Calculate late return fine
- Simple command-line interface

## Technologies Used

- Python 3
- Lists
- Loops

- Input and output
- Basic Python programming

No external libraries are required.
